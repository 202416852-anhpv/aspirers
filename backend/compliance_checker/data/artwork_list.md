# Artwork List — Commonly copyrighted artwork/franchises

*Source: manually compiled. Last updated: 2026-08-20.*

## Copyrighted image franchises (illustration, key art, movie poster style)
Disney/Pixar movie posters & key art, Marvel Cinematic Universe poster art, Studio Ghibli film stills, Star Wars poster art, Harry Potter book covers & film stills, Pokémon official artwork.

## Famous fine art STILL under copyright (distinct from public domain)
Note: many classical paintings (Van Gogh, Monet...) are already public domain (copyright expired) — do NOT auto-flag just because a painting is "famous". Only flag CONTEMPORARY work or work still within its protection term: illustrations by well-known contemporary illustrators on Etsy/Instagram (case-by-case risk, hard to list exhaustively by name), AAA game key art (Genshin Impact, League of Legends splash art), album covers still under copyright.

## Usage note
This group is harder to cross-reference against a static text list than Character/Logo because the scope is very broad and new works appear constantly — it relies mainly on Agent 2's zero-shot Vision judgment. This list only suggests commonly high-risk groups seen in POD, it is NOT an exhaustive matching list.

(2026-08-22, policy update) There is no reliable static name-list to cross-reference artwork against — verdict for this category depends entirely on the agent's own reasoning. Even without a confirmed database match, if Agent 2 is genuinely confident a design closely reproduces or derives from a specific copyrighted artwork/franchise and explains it thoroughly (which work, why it's confident), this can still escalate to BLOCKED. The agent has the authority to flag it, provided the reasoning clearly states which artwork/franchise it resembles and explicitly recommends a quick manual verification, precisely because there is no database confirmation behind it.
